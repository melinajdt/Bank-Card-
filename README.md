#  Bank Card UI

✨ A modern, stylish, and interactive bank card interface designed with a bold black and hot pink aesthetic.

Welcome to **Pink Glow — Bank Card UI**, a front-end project focused on creating a sleek banking-inspired design with neon pink accents, glowing effects, and a clean user interface.

## 🎀 Features

- 🖤 **Dark UI Design** — A sleek black background with a modern aesthetic.
- 💗 **Neon Pink Accents** — Vibrant pink colors and glowing visual effects.
- 💳 **Bank Card Interface** — A stylish banking-inspired card design.
- ✨ **Modern Styling** — Carefully designed layouts, borders, and visual details.
- 📱 **Responsive Layout** — An adaptable layout for different screen sizes.
- ⚡ **Interactive Elements** — JavaScript-powered functionality.
- 🎨 **Custom Color Palette** — A cohesive black and pink visual identity.

## 🛠️ Built With

- 🌐 **HTML5** — Page structure and content.
- 🎨 **CSS3** — Styling, layout, animations, and visual effects.
- ⚡ **JavaScript** — Interactive functionality.
